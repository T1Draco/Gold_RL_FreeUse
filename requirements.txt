#    
#    B) WINDOWS/LINUX sin GPU (solo CPU):
#       El torch del requirements.txt ya funciona (por defecto es CPU)
#    
#    C) macOS (Apple Silicon M1/M2/M3):
#       pip install torch  # Usa Metal Performance Shaders automáticamente
